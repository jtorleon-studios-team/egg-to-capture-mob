## Intro :

Want to capture mobs in Minecraft? You've found the right mod! This mod introduces a new capture egg that allows you to capture any mob, entity, or monster. Simply throw the egg at the target to transform it into a spawn egg for easy storage and transportation. But be careful – you'll need to weaken the target before you can successfully capture it. Each capture unlocks an advancement!

- Capture any mob, monster, or entity with a special egg
- Unlock advancements for each successful capture
- Unique and exciting capture mechanics
- More features coming in future updates!
